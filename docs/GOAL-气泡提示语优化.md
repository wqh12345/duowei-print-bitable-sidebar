# 1. 需求记录（用户视角）

插件当前的气泡提示（顶部状态浮条 status-line，约 2.6s 自动收起；以及按钮 `title` 悬浮气泡）存在三类问题：

1. **噪音**：用户自己点击取消、或界面上已经能直接看到结果的场景仍然弹泡（如"未选择记录，保持原状态""模板已重命名"）。
2. **术语**：面向开发者而非办公人员（如"草稿""宿主""批次候选""未写入当前记录值"）。
3. **不一致**：同一只读权限提示有 3 种不同措辞；同类失败提示句式各异。

# 2. SDD：提示语存在性规格

一条气泡只有在满足以下四条之一时才允许存在：

- **C1 失败回执**：用户主动操作未成功——必须说明「没发生什么 ＋ 数据是否安全 ＋ 下一步」。
- **C2 前置拦截**：按钮/操作被条件阻塞——说明原因并指向解除办法。
- **C3 结果不可见**：产出无法在当前界面直接确认（PDF 页数与大小、复制后的粘贴指引）。
- **C4 权限说明**：文档权限导致功能不可用，全站统一一句：
  **「没有编辑权限，无法修改模板或打印」**

不满足 C1～C4 的成功/取消回执一律静默（删除 `status` 写入，保留数据逻辑）。

术语对照（一律替换）：草稿→未保存的修改；批次→批量打印记录；目录→模板列表；宿主/记录视图→表格；候选/提交/回退等实现词禁止出现。
句式：失败类「X 未 + 动词，…保持不变/可重试」；拦截类「请先…」；动词开头、≤25 字优先。
